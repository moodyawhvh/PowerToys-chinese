# PowerToys Run 第三方插件

以下是由社区创建的 PowerToys Run 第三方插件合集。

## 安装与升级第三方 PowerToys Run 插件

推荐的插件安装路径是 `%LOCALAPPDATA%\Microsoft\PowerToys\PowerToys Run\Plugins`。

1. 关闭 PowerToys。
1. 将插件文件夹复制到 `%LOCALAPPDATA%\Microsoft\PowerToys\PowerToys Run\Plugins`。
1. 如果是升级插件,请删除旧版本。
1. 重新打开 PowerToys。

更多细节请参阅各插件自己的说明。
